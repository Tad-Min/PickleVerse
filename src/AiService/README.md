# PickleVerse Hybrid AI

Internal, stateless FastAPI service. Unity sends completed-session telemetry to ASP.NET; the PostgreSQL job worker invokes this service. Python never writes player data or Elo.

## Run locally

Use Python 3.12 and a dedicated virtual environment. Install `requirements-dev.txt` for development or `requirements.txt` for serving. Dependencies are constrained by `requirements-lock.txt`.

Set `AI_SERVICE_KEY` to a dedicated random secret of at least 32 characters, then:

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 18080 --no-access-log
python -m pytest -q
```

Run pytest from `src/AiService`. The project configuration discovers the suites in `src/Testing/AiService`. [Repository testing guide](../Testing/README.md)

`GET /health` reports process health. `GET /ready` checks service-key configuration and reports rules/model status. Docker healthchecks use `/ready`, so a missing service key makes the container unhealthy. `POST /v1/analyze-session` requires `X-AI-Key`. Docker exposes this service only on the internal Compose network.

The local development activation and in-game testing guide is [AI service testing](../../Doc/AI_Service_Activation_20261031.md).

The shared request fixture is `contracts/hybrid-ai/session-v1.json`. Coordinates use game meters and timing errors are signed seconds. Missing values are unknown. The engine excludes autogenerated aim from human accuracy and uses observed release timing when assisted contact replaces the result of the original input. `DinkTooHigh` requires an independently evaluated, expert-approved calibration artifact whose configured SHA-256 and runtime context match.

## Offline tier training

No production model or expert-labeled dataset is bundled. Serving uses rule/curriculum fallback by default.

Use the admin dataset export for independently assessed player labels and the review provenance. The [collection and review guide](../../Doc/AI_Expert_Review.md) covers the capture protocol, partition assignment and commands. Synthetic records exercise the pipeline in tests.

```powershell
python train.py labeled.json models/tier.joblib --version tier-v1 --mode training --assisted true
```

The pipeline fits preprocessing and the classifier on training players, fits probability calibration on separate players and evaluates on an independent holdout. The manifest includes dataset and model checksums, player partitions, mode, assistance context, feature version and evaluation metrics. Holdout scoring counts abstentions at the serving threshold. Activation requires at least ten holdout players per tier, macro-F1 >= 0.70 and improvement >= 0.05 over majority baseline.

Only deploy trusted, locally trained artifacts. Set `AI_ENABLE_MODEL=true` and `AI_MODEL_PATH` to the approved artifact. The adjacent `.json` manifest must be deployed together with the `.joblib`. Docker reads `src/AiService/models/` as a read-only volume. A missing, altered or unapproved artifact leaves tier inference unavailable; rules continue to work.

Inference requires at least 20 observable opportunities, a matching mode/assistance context and confidence >= 0.65. The estimate suggests practice difficulty and drills; it does not change competitive Elo.

`calibrate_coaching.py` uses independently reviewed shot labels and evaluates each selected error code at precision >= 0.80 and recall >= 0.70. Keep the approved report at `AI_COACHING_CALIBRATION_PATH` and set `AI_COACHING_CALIBRATION_SHA256` to the exact artifact digest. The service ignores caller-supplied Dink thresholds and uses the reviewed threshold only in the calibrated game context.

### Simulated Training demo

Generate a reproducible demo with 30 virtual players, one Volley session per player and 24 attempts per session. Each tier has six training players, two calibration players and two test players. The timing, input and recovery parameters are scenario choices. Every row has `labelSource: "simulation"` and `synthetic: true`. Train the simulation in a separate dataset and keep the output outside the serving model directory.

```powershell
python simulate_training.py ../../artifacts/ml-demo-30/training-simulated.json
python train.py ../../artifacts/ml-demo-30/training-simulated.json ../../artifacts/ml-demo-30/tier-demo.joblib --version tier-demo-v1 --assisted true
```

The report shows the pipeline's behavior on the simulated profiles. The service's artifact gate requires expert evidence and keeps the demo model unavailable for serving.
