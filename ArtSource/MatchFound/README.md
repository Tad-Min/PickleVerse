# Match found: paddles, VS ball and intro

Source of the ready-check ("ĐÃ TÌM THẤY TRẬN") intro shown by `MatchReadyOverlay` / `MatchFoundStage` in Unity.
Blender 5.1, everything is generated by scripts (no hand edits in the .blend files).

| Script | Output |
| --- | --- |
| `paddle_shape.py` | Shared outline of the PickleVerse Elongated paddle (used by the texture and the mesh). |
| `make_paddle_textures.py` | `textures/pv_paddle_albedo.png`, `pv_paddle_normal.png` (1024x2048 atlas: face graphics + overgrip). |
| `build_paddle.py` | `pv_paddle.blend`, `PV_Paddle_Elongated.glb` (5,942 triangles); optional beauty render. |
| `make_fx_noise.py` | `unity/pv_fx_noise.png`, 256x256 tileable fBm for the smoke and wave shaders. |
| `export_unity_assets.py` | `unity/PV_Paddle_Elongated.fbx`, `unity/PV_VS_Ball.fbx` (2,591 triangles) for `Assets/Resources/MatchFound`. |
| `build_match_found.py` | `match_found_vs.blend`, the approved preview: rally, bullet time, cross, VS lock, avatar states. |
| `encode_mp4.py` | Joins rendered frames into an H.264 preview with Blender's sequencer. |

```
python make_paddle_textures.py textures
blender --background --factory-startup --python build_paddle.py
python make_fx_noise.py unity/pv_fx_noise.png
blender --background --factory-startup --python export_unity_assets.py -- unity
blender --background --factory-startup --python build_match_found.py -- <frames_dir> anim
```

The Unity port (`MatchFoundChoreography.cs`) evaluates the same choreography in C#; keep both in step when changing
timings. FBX meshes import into Unity as (x, y, z) -> (-x, z, -y).
