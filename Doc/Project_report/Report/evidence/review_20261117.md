## 3. Findings of the code review

- The MP4 upload of the social feed is compiled only for the Unity Editor (`#if UNITY_EDITOR` in
  `SocialLobbyMenu.Feed.cs`, method `PickVideo`). A Windows or Android build shows "Tải video hiện khả dụng trong Unity
  Editor." Text posts, shared replays and video playback are not limited in this way. Logged as defect D-22.
- In runs 35, 42–48 and 51 the pipeline passed but the job "Deploy Linux development" was skipped. It ran only in runs
  38, 39 and 52, the runs in which the FastAPI and admin web jobs also ran (ci_runs_20261117.json). Staging therefore
  stayed on the release of run 39 (ab7fc89) until run 52 deployed 96ff8e9. Logged as defect D-23.
- The commit message of e160b4e mentions automatic pausing when the application loses focus; the code releases the
  held input (bot match, training) and keeps the match running.
