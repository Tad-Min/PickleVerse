## Found by reading the code along the workflow

- **D-33 (Critical).** `OnlinePlayerEconomy.ApplyCatalog` threw an exception for a shop item that the build does not know. It runs inside
  `ProgressionRuntime.Changed`, so every profile load and command of every player failed as soon as an administrator added an item whose
  code starts with `paddle.` in the CMS, or when the server sells an item of a newer build. Fixed on 25/11/2026: the client skips unknown
  items (`OnlinePlayerEconomy.Merge`, two EditMode tests) and the API no longer sends items without game configuration
  (`GameRepository.Catalog`, check in the content group). EditMode 710/710 (EV-18); the backend builds without warnings; the database check
  runs in the pipeline with the next push.
